关于此风格

自然/有机设计风格强调与自然世界的联系，旨在创造一种平静、舒适和脚踏实地的视觉体验。它经常借鉴自然界的色彩、纹理和形式，以唤起和谐、可持续性和温暖的感觉。

这种风格非常适合与健康、环保、生活方式、手工艺品相关的品牌或项目，或任何希望传达真实性、质朴感和宁静感的场合。

主要特点:

  • 大地色系调色板 (Earthy Color Palette): 主要使用源自自然的颜色，如棕色、米色、奶油色、灰色、柔和的绿色和蓝色。
  • 自然纹理 (Natural Textures): 可能包含微妙的纸张、木纹、石头或织物（如亚麻）纹理，以增加触感和深度，但通常不会过于强烈。
  • 柔和的光影 (Soft Lighting and Shadows): 避免刺眼、强烈的阴影，倾向于模仿自然光照的柔和、漫射的光效。
  • 简洁的布局 (Clean Layout): 通常采用简单的布局和充足的留白，以营造呼吸感和宁静感。
  • 人文主义字体 (Humanistic Fonts): 经常使用易于阅读的无衬线字体（如 Lato）或带有柔和曲线的衬线字体，给人一种友好、平易近人的感觉。
  • 圆角和有机形状 (Rounded Corners & Organic Shapes): 可能使用适度的圆角和不完全规则的形状，模仿自然界中的曲线。
  • 强调可持续性 (Emphasis on Sustainability): 设计理念可能与环境保护和可持续发展相一致。

示例 AI Prompt

Design a website interface with a natural and organic style. Use an earthy color palette dominated by beige (#f5f0e1), soft browns (#8b7e66), and muted greens. Apply a subtle paper or linen texture to the background. Use the 'Lato' font for body text and headings. Keep the layout clean with generous whitespace. Use soft, diffused shadows for elements like cards (#ffffff background, border #d4c8a8). Buttons should have slightly rounded corners and use colors from the palette (e.g., primary #8b7e66, secondary #d4c8a8). The overall mood should be calm, grounded, and welcoming.

（中文解释：设计一个具有自然和有机风格的网站界面。使用以米色（#f5f0e1）、柔和棕色（#8b7e66）和低饱和度绿色为主的大地色系。在背景上应用微妙的纸张或亚麻纹理。正文和标题使用 'Lato' 字体。保持布局简洁，留有充足的空白。为卡片（#ffffff 背景，#d4c8a8 边框）等元素使用柔和、弥散的阴影。按钮应具有略微圆角，并使用调色板中的颜色（例如，主色 #8b7e66，次要色 #d4c8a8）。整体感觉应是平静、踏实和友好的。）

主题 CSS 代码片段

以下是将此自然/有机风格应用为全局主题的核心 CSS 代码 (body.theme-natural-organic)。它定义了颜色、字体和基础元素样式：


/* ==========================================================================
   15. Natural / Organic Theme
   ========================================================================== */

body.theme-natural-organic {
    --page-bg: #f5f0e1; /* Beige background */
    --page-bg-gradient: none;
    /* Optional: Add subtle texture via background-image */
    /* background-image: url("path/to/linen-texture.png"); */
    --text-color: #5e4a30; /* Dark, warm text color */
    --heading-color: #3c2f2f; /* Darker heading color */
    --link-color: #8b7e66; /* Soft brown link */
    --link-hover-color: #7a6f5a; /* Darker brown hover */
    --border-color: #d4c8a8; /* Light brown/beige border */
    --card-bg: #ffffff; /* White card background */
    --card-shadow: 0 1px 3px rgba(0,0,0,0.05); /* Soft shadow */
    --card-hover-shadow: 0 3px 8px rgba(0,0,0,0.08); /* Slightly stronger soft shadow */
    --header-bg: #8b7e66; /* Header uses soft brown */
    --header-text-color: #ffffff;
    --header-shadow: none;
    --footer-text-color: #8b7e66; /* Footer text matches link color */
    --footer-bg: #f5f0e1; /* Footer matches page background */
    --button-bg: #8b7e66; /* Primary button uses soft brown */
    --button-text-color: white;
    --button-hover-bg: #7a6f5a;
    --button-border: none;
    --button-secondary-bg: #d4c8a8; /* Secondary button uses border color */
    --button-secondary-text-color: #5e4a30; /* Dark text on light button */
    --button-secondary-hover-bg: #c8bca0;
    --button-secondary-border: none;
    --prompt-bg: #e8e0c9; /* Lighter beige for prompt area */
    --prompt-text-color: #6b5b40; /* Slightly darker text for prompt */
    --base-font: var(--font-lato); /* Use Lato font */
    --heading-font: var(--font-lato); /* Use Lato font for headings too */
    --card-border-radius: 6px; /* Gentle rounded corners */
    --button-border-radius: 4px; /* Slightly rounded buttons */
}

/* Specific adjustments for the theme */
body.theme-natural-organic .card {
    border: 1px solid var(--border-color); /* Ensure cards have the border */
}

body.theme-natural-organic h1,
body.theme-natural-organic h2,
body.theme-natural-organic h3 {
    font-weight: 700; /* Make headings slightly bolder */
}

/* Ensure buttons inherit theme colors */
body.theme-natural-organic .btn {
    background-color: var(--button-bg);
    color: var(--button-text-color) !important;
    border-radius: var(--button-border-radius);
}
body.theme-natural-organic .btn:hover {
    background-color: var(--button-hover-bg);
}
body.theme-natural-organic .btn-secondary {
    background-color: var(--button-secondary-bg);
    color: var(--button-secondary-text-color) !important;
}
body.theme-natural-organic .btn-secondary:hover {
    background-color: var(--button-secondary-hover-bg);
}

注意：为获得最佳效果，可以考虑为 `--page-bg` 添加非常微妙的无缝纹理背景图像。阴影应保持柔和，避免过于强烈的三维效果。
