关于此风格

现代科技风格是现代设计原则在数字产品、软件界面和技术相关网站上的具体应用。它优先考虑清晰度、效率和用户体验，通常带有一种精确、前沿的感觉。

主要特点:

  • 清晰界面 (Clean Interface): 布局结构化，利用卡片、模块化设计和足够的留白来组织信息。
  • 现代无衬线字体 (Modern Sans-serif): 如 Inter, Poppins, SF Pro 等，注重易读性和不同字重的使用。
  • 功能性图标 (Functional Icons): 使用清晰、一致的图标系统（如 Material Icons, Font Awesome）来辅助导航和操作。
  • 冷色调与强调色 (Cool Palette & Accents): 常用蓝色、紫色、深灰、白色作为基础色，搭配明亮的强调色（如亮蓝、绿色）用于交互元素。
  • 渐变与阴影 (Gradients & Shadows): 可能使用微妙的渐变增加活力，使用柔和、精确的阴影提升层次感。
  • 数据可视化 (Data Visualization): 如果适用，会包含清晰、美观的图表（线形图、柱状图、饼图等）。
  • 微交互 (Microinteractions): 通过细微的动画反馈（如按钮悬停、加载状态）提升用户体验。
  • 暗黑模式 (Dark Mode): 提供或默认使用暗色主题是一种常见的科技风格特征，有助于减少视觉疲劳。

这种风格非常适合 SaaS 平台、应用程序着陆页、在线工具、技术文档、仪表盘和任何需要传递专业、高效、创新感觉的数字界面。

示例 AI Prompt

Design a modern tech dashboard UI for data analytics. Use a clean layout with cards, charts (bar, line), Inter or Poppins font, a cool color palette (blues, purples, greys), clear data visualization, and subtle hover effects.

（中文解释：为数据分析设计一个现代科技风格的仪表盘用户界面。使用包含卡片、图表（柱状图、线形图）的简洁布局，Inter 或 Poppins 字体，冷色调配色方案（蓝色、紫色、灰色），清晰的数据可视化，以及微妙的悬停效果。）

    /* Slightly darker, cooler background with subtle gradient */
    --page-bg: #49efed; /* UPDATED */

    --text-color: #181c22; /* Slightly darker text */
    --heading-color: #0b132b; /* Keep dark blue heading */
    /* More vibrant tech blue */
    --link-color: #4d5bff;
    --link-hover-color: #3a4bf0;
    --border-color: #000000; /* UPDATED */
    --card-bg: #49ecef; /* UPDATED */
    /* Slightly more defined shadow */
    --card-shadow: 0 3px 10px rgba(29, 35, 42, 0.08);
    --card-hover-shadow: 0 5px 15px rgba(29, 35, 42, 0.12);
    --header-bg: #ffffff;
    --header-text-color: var(--text-color);
    /* Keep subtle header shadow */
    --header-shadow: 0 1px 3px rgba(29, 35, 42, 0.05);
    --footer-text-color: #6c757d;
    --footer-bg: var(--page-bg);
    /* Button with subtle gradient and glow on hover */
    --button-bg: linear-gradient(to bottom, #5a6aff, #4d5bff);
    --button-text-color: white;
    --button-hover-bg: linear-gradient(to bottom, #4d5bff, #3a4bf0);
    --button-border: none;
    --button-shadow: 0 1px 2px rgba(77, 91, 255, 0.2);
    /* Add hover shadow/glow */
    --button-hover-shadow: 0 2px 4px rgba(77, 91, 255, 0.2), 0 0 8px rgba(77, 91, 255, 0.3);
    --button-secondary-bg: #e9ecef;
    --button-secondary-text-color: #495057;
    --button-secondary-hover-bg: #dee2e6; /* Slightly darker hover */
    --button-secondary-border: none;
    --prompt-bg: #eef2f7;
    --prompt-text-color: #343a40;
    --base-font: var(--font-pop);
    --heading-font: var(--font-pop);
    /* Sharper corners */
    --card-border-radius: 4px;
    --button-border-radius: 2px;
    --mono-font: var(--font-roboto-mono);
}

}
