A working library of AI website prompts, not just a gallery

Every entry on this page answers three practical questions: what the style actually looks like, when it is the right choice for a project, and the exact prompt you can paste into an AI website builder to reproduce it. There are currently 22 documented styles, each with a full breakdown page covering colour tokens, typography, layout rhythm, common failure modes, and a downloadable CSS starter.

Most prompt lists stop at a one-line description. That is not enough to build with. A prompt like "make it glassmorphism" produces wildly different results depending on which model you use, what container it is dropped into, and whether contrast was specified. So each prompt here is written with explicit constraints: what to include, what to forbid, and which CSS properties carry the effect.

How to use this library

  1. Pick a direction. Browse the 22 styles below. Use "Apply Theme" to preview the palette directly on this page before committing.
  2. Read the breakdown. Open a style to see its design tokens and the failure cases — the parts that break first when generated by an AI.
  3. Copy the prompt. Paste it into your builder, then append your own product details. The prompts are written to be extended, not used verbatim.
  4. Start from the CSS. If the model drifts, take the downloadable stylesheet as ground truth and ask it to match.

Frequently asked questions

Can an AI actually build a good-looking website from a single prompt?

A single sentence will get you a layout, but not a coherent visual system. The prompts that work specify five things: the visual direction, the constraints (fonts, spacing, radius), the content structure, the interaction behaviour, and what to avoid. Leaving out constraints is why most first-attempt results look generic.

Which style should I start with for a SaaS landing page?

For most product sites in 2026 the safe defaults are Modern Tech (clean cards, restrained accent colour) or Bento Grid (modular tiles that carry many features without visual noise). Choose Brutalism or Maximalism only when the brand voice is explicitly loud, because they are hard to keep readable.

Why do AI-generated designs all look the same?

Because the model defaults to the statistical average of its training data: Inter, a soft purple gradient, and 16px rounded cards. Breaking out of that requires naming an alternative typographic tradition and an explicit palette, which is exactly what each prompt here does.

Do these prompts work with v0, Lovable, Bolt and Claude?

Yes, with small edits. Tools that output React components respond well to component-level prompts. Tools that output a single HTML file need the structure spelled out as a page outline instead. The style prompts here are tool-agnostic; only the delivery instructions differ.

Are the downloadable CSS files free to use?

Yes. Each style page offers a standalone CSS file you can drop into any project. Attribution is appreciated but not required.
