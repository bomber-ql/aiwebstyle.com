关于此风格

拟泥化（Claymorphism），或称黏土风，是一种追求柔和、友好、略带3D感的界面设计风格。它通过模拟黏土或橡皮泥的质感，使用圆润的形状和内外阴影来创造出一种轻盈、可爱的立体效果，与新拟物化（Neumorphism）的硬朗感有所区别。

这种风格通常给人一种平易近人、充满童趣或现代卡通的感觉，适合用于需要营造轻松、有趣氛围的应用和网站。

主要特点:

  • 圆润的形状 (Rounded Shapes): 元素（如卡片、按钮）通常具有非常圆滑的边角，模仿黏土被捏塑后的形态。
  • 柔和的内外双重阴影 (Soft Inner & Outer Shadows):
    • 外阴影 (Outer Shadow): 通常是一个柔和、弥散的深色阴影，使元素看起来像是轻微浮起在背景之上。
    • 内阴影 (Inner Shadow): 通常是一个柔和、弥散的浅色（或同色系更亮）阴影，模拟光线在元素边缘的反射，增强其“鼓胀”感。
  • 平滑的表面 (Smooth Surfaces): 元素表面通常是平滑的，没有过多的纹理，颜色也多为纯色或非常柔和的渐变。
  • 色彩柔和友好 (Soft & Friendly Colors): 常使用粉彩色系、柔和的亮色或中性色，避免过于刺眼或深沉的颜色。
  • 轻微的“浮动感” (Slight "Floating" Feel): 元素看起来像是轻轻地漂浮在背景上，而不是完全扁平或深深嵌入。
  • 可爱的交互反馈 (Playful Interactions): 按钮按下时，阴影可能会反转（外阴影变内阴影），模拟被按压的效果。

示例 AI Prompt

Design a user interface with a Claymorphism style. Use a light, friendly background color (e.g., #e0e5ec). Elements like cards and buttons should have heavily rounded corners (e.g., border-radius: 20px or more). Apply a soft outer shadow (e.g., 3px 3px 5px rgba(0,0,0,0.1)) and a soft inner shadow (e.g., inset -3px -3px 7px rgba(255,255,255,0.7)) to create a "puffy" or "clay-like" 3D effect. Use a sans-serif font like 'Poppins'. Colors for elements should be soft and appealing (e.g., pastel blues, pinks, or light earthy tones like #e8c3a0). Buttons should have a distinct pressed state where shadows might invert.

（中文解释：设计一个拟泥化风格的用户界面。使用浅色、友好的背景色（例如 #e0e5ec）。卡片和按钮等元素应具有非常圆滑的边角（例如 border-radius: 20px 或更大）。应用柔和的外阴影（例如 3px 3px 5px rgba(0,0,0,0.1)）和柔和的内阴影（例如 inset -3px -3px 7px rgba(255,255,255,0.7)）来创建“蓬松”或“黏土般”的3D效果。使用像 'Poppins' 这样的无衬线字体。元素的颜色应柔和且吸引人（例如柔和的蓝色、粉色或浅土色调如 #e8c3a0）。按钮应具有独特的按下状态，此时阴影可能会反转。）

主题 CSS 代码片段

以下是将此拟泥化风格应用为全局主题的核心 CSS 代码 (body.theme-claymorphism)。它定义了柔和的颜色、圆角以及标志性的内外阴影：


/* ==========================================================================
   18. Claymorphism Theme
   ========================================================================== */

body.theme-claymorphism {
    /* Base colors for Claymorphism */
    --clay-bg: #e0e5ec; /* Light greyish blue, common for claymorphism */
    --clay-text: #5a6674; /* Muted text color */
    --clay-heading: #3d4a5a; /* Slightly darker heading */
    --clay-accent: #a3b1c6; /* Accent color, can be used for hovers or secondary elements */
    --clay-highlight: #ffffff; /* Highlight color, often for inner shadows */
    
    /* Shadow colors - adjust opacity and color as needed */
    --clay-shadow-color-dark: rgba(0, 0, 0, 0.1); 
    --clay-shadow-color-light: rgba(255, 255, 255, 0.7);

    /* Claymorphism shadows */
    --clay-shadow-inset: inset 2px 2px 5px var(--clay-shadow-color-dark), 
                         inset -3px -3px 7px var(--clay-shadow-color-light);
    --clay-shadow-outset: 3px 3px 5px var(--clay-shadow-color-dark), 
                          -3px -3px 7px var(--clay-shadow-color-light);
    /* Stronger outset shadow for hover states */
    --clay-shadow-outset-hover: 5px 5px 10px var(--clay-shadow-color-dark), 
                                -5px -5px 10px var(--clay-shadow-color-light);


    /* Apply Claymorphism variables to theme properties */
    --page-bg: var(--clay-bg);
    --page-bg-gradient: none;
    --text-color: var(--clay-text);
    --heading-color: var(--clay-heading);
    --link-color: var(--clay-heading); /* Links can use heading color */
    --link-hover-color: var(--clay-accent);
    
    --border-color: transparent; /* Claymorphism usually avoids hard borders */
    
    --card-bg: var(--clay-bg); /* Cards use the same bg as page, relying on shadows for definition */
    --card-shadow: var(--clay-shadow-outset);
    --card-hover-shadow: var(--clay-shadow-outset-hover);
    
    --header-bg: var(--clay-bg);
    --header-text-color: var(--clay-heading);
    --header-shadow: var(--clay-shadow-outset); /* Header can also have clay effect */
    
    --footer-text-color: var(--clay-text);
    --footer-bg: var(--clay-bg);
    /* Footer might not need a shadow or a very subtle one */
    
    --button-bg: var(--clay-bg); /* Buttons also use page bg */
    --button-text-color: var(--clay-text);
    --button-hover-bg: var(--clay-accent); /* Or change shadow on hover */
    --button-border: none;
    --button-shadow: var(--clay-shadow-outset);
    --button-hover-shadow: var(--clay-shadow-outset-hover); /* Or use inset for pressed state */
    
    --button-secondary-bg: var(--clay-bg);
    --button-secondary-text-color: var(--clay-text);
    --button-secondary-hover-bg: var(--clay-accent);
    --button-secondary-border: none;
    /* Secondary buttons might have slightly different shadow or be flatter */

    --prompt-bg: var(--clay-bg); /* Prompt area can be inset */
    --prompt-text-color: var(--clay-text);
    --prompt-shadow: var(--clay-shadow-inset); /* Inset shadow for prompt area */
    
    --base-font: var(--font-pop); /* Poppins is a good fit */
    --heading-font: var(--font-pop);
    
    --card-border-radius: 20px; /* Significant rounding */
    --button-border-radius: 15px; /* Also very rounded */
}

/* Specific adjustments for the Claymorphism theme */
body.theme-claymorphism .card {
    border: none; /* Remove default border if any */
}

body.theme-claymorphism .btn {
    transition: box-shadow 0.15s ease-in-out, transform 0.15s ease-in-out, background-color 0.15s ease-in-out;
}
body.theme-claymorphism .btn:active { /* Pressed state */
    box-shadow: var(--clay-shadow-inset);
    transform: translateY(1px); /* Slight press down effect */
}

body.theme-claymorphism h1,
body.theme-claymorphism h2,
body.theme-claymorphism h3 {
    /* Optional: Add subtle text shadow to make headings pop a bit from the clay surface */
    text-shadow: 1px 1px 1px var(--clay-shadow-color-light); 
    font-weight: 600; /* Poppins often looks good semi-bold */
}

/* Ensure prompt/code areas within sections get the inset shadow */
body.theme-claymorphism .style-detail-section pre {
    background-color: var(--prompt-bg);
    color: var(--prompt-text-color);
    box-shadow: var(--prompt-shadow);
    border-radius: var(--button-border-radius); /* Match button radius for consistency */
    border: none;
}

注意：拟泥化的关键在于内外阴影的巧妙运用和非常圆润的边角。调整阴影的颜色、模糊度和偏移量可以创造出不同的“黏土”质感。
