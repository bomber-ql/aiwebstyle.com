关于此风格

粗体排版风格是一种将文字，特别是大型、醒目的标题作为设计核心元素的网页设计方法。它不仅仅是选择粗体字重，而是围绕排版本身来构建视觉层次和冲击力。

这种风格通常追求简洁、直接和有力，通过字体的选择、大小、间距和布局来传达信息和情感。

主要特点:

  • 巨大的标题 (Oversized Headlines): 标题通常占据屏幕的显著位置，字号极大，成为视觉焦点。
  • 强烈的字体选择 (Strong Font Choices): 倾向于使用无衬线体（Sans-serif）或具有强烈个性的字体，特别是那些拥有极粗字重（如 Black, Ultra Bold）的字体。例如 Montserrat, Anton, Oswald, Inter (900)。
  • 高对比度 (High Contrast): 常常采用简单的、高对比度的配色方案（如黑白、白底亮色字），以突出文字。
  • 排版即设计 (Typography as Design): 文字不仅仅是内容载体，其形状、排列和负空间本身就构成了设计的主要视觉元素。
  • 清晰的层级 (Clear Hierarchy): 尽管标题醒目，但通过字号、字重和间距的精心安排，依然能建立清晰的信息层级。
  • 极简主义倾向 (Minimalist Tendencies): 为了让排版成为主角，通常会减少其他装饰性元素（如图形、复杂背景）的使用。
  • 强调可读性 (Emphasis on Readability): 即使字号很大，也要确保在不同屏幕尺寸下的可读性。注意行高和字间距的调整。

粗体排版风格非常适合需要快速传达核心信息、展现力量感和现代感的网站，如活动宣传、作品集、品牌宣言、新闻标题或任何希望通过文字产生强烈第一印象的场景。

示例 AI Prompt

Design a website landing page using a bold typography style. Feature a massive headline using the 'Anton' font or 'Montserrat' (900 weight). Use a high-contrast black and white color scheme with one minimal accent color (e.g., bright yellow) for calls to action. Keep layout clean and focused on the text hierarchy.

（中文解释：使用粗体排版风格设计一个网站着陆页。采用一个巨大的标题，使用 'Anton' 字体或 'Montserrat' (900 字重)。使用高对比度的黑白配色方案，并为号召性用语添加一种简约的强调色（例如亮黄色）。保持布局简洁，并专注于文本层级。）

主题 CSS 代码片段

以下是将粗体排版风格应用为全局主题的核心 CSS 代码 (body.theme-bold-typography):

/* 4. Bold Typography Theme */
body.theme-bold-typography {
    /* High contrast background and text */
    --page-bg: #ffffff;
    --page-bg-gradient: none;
    --text-color: #111111; /* Near black text */
    /* Use a very bold font for headings */
    --heading-font: var(--font-montserrat); /* Or Anton, Oswald etc. */
    --heading-color: #000000; /* Pure black headings */
    --heading-font-weight: 900; /* Crucial: Use the heaviest weight */
    --link-color: #000000; /* Links match text or use accent */
    --link-hover-color: #555555;
    --border-color: #dddddd; /* Light grey border */
    --card-bg: #f9f9f9; /* Very light grey card */
    --card-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
    --card-hover-shadow: 0 4px 12px rgba(0, 0, 0, 0.12);
    --header-bg: #ffffff;
    --header-text-color: var(--heading-color);
    --header-shadow: none; /* Often minimal shadow */
    border-bottom: 1px solid #eee;
    --footer-text-color: #666666;
    --footer-bg: #f1f1f1;
    /* Accent color for buttons - can be changed */
    --button-bg: #000000; /* Black button */
    --button-text-color: #ffffff; /* White text */
    --button-hover-bg: #333333;
    --button-border: none;
    --button-secondary-bg: transparent;
    --button-secondary-text-color: #000000;
    --button-secondary-hover-bg: #f0f0f0;
    --button-secondary-border: 1px solid #000000;
    --prompt-bg: #f0f0f0; /* Light grey prompt */
    --prompt-text-color: #333333;
    --base-font: var(--font-inter); /* Use a clean sans-serif for body */
    --card-border-radius: 4px; /* Sharper corners */
    --button-border-radius: 2px; /* Very sharp button corners */
}

/* Bold Typography Specific Adjustments */
body.theme-bold-typography h1,
body.theme-bold-typography h2,
body.theme-bold-typography h3 {
    font-family: var(--heading-font);
    font-weight: var(--heading-font-weight); /* Ensure heavy weight is applied */
    letter-spacing: -0.02em; /* Slightly tighter letter spacing for impact */
    margin-bottom: 0.5em; /* Adjust spacing */
    line-height: 1.1; /* Tighter line height for large headings */
    text-transform: uppercase; /* Optional: Uppercase for more impact */
}

/* Example: Make H1 extremely large */
body.theme-bold-typography h1 {
    font-size: clamp(3rem, 10vw + 1rem, 8rem); /* Responsive large font size */
}

body.theme-bold-typography h2 {
    font-size: clamp(2rem, 5vw + 1rem, 4rem);
}

body.theme-bold-typography .btn {
    font-weight: 700; /* Bold button text */
    text-transform: uppercase; /* Uppercase buttons */
    letter-spacing: 0.05em;
}

注意：粗体排版的核心在于字体的选择和层级设计。上述 CSS 提供了基础框架，实际应用中需要根据内容调整字号、间距和具体字体。
