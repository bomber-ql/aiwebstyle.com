关于此风格

单色系设计风格（Monochromatic Design）是一种仅使用单一基础颜色及其不同色调（tints - 加入白色）、色度（shades - 加入黑色）和饱和度（tones - 加入灰色）变化的配色方案。这种方法创造出一种和谐、统一且通常非常优雅和精致的视觉效果。

尽管颜色选择受限，单色系设计可以通过巧妙地运用对比度、纹理和排版来构建视觉层次和焦点，避免单调感。

主要特点:

  • 单一基础色 (Single Base Hue): 整个设计围绕一个核心颜色展开，例如蓝色、绿色或灰色。
  • 色调、色度和饱和度变化 (Variations in Tints, Shades, and Tones): 通过改变基础色的亮度和饱和度来创建丰富的色彩层次。例如，从浅蓝色到深海军蓝。
  • 强调对比度 (Emphasis on Contrast): 即使在单一颜色内，也通过明暗、饱和度的对比来区分元素和引导视线。
  • 和谐统一 (Harmony and Unity): 由于颜色的一致性，整体视觉效果非常和谐，元素之间关联紧密。
  • 简洁与精致 (Clean and Sophisticated): 单色系常与简约主义相关联，能够传递出专业、现代和成熟的感觉。
  • 排版与留白的重要性 (Importance of Typography and Whitespace): 在颜色变化有限的情况下，优秀的排版和充足的留白对于创建清晰的视觉结构至关重要。

单色系设计适用于品牌希望传达专注、稳定和高品质感的场景，如企业网站、作品集、高端产品展示等。它可以是任何颜色，不仅仅是黑白灰。

示例 AI Prompt (以蓝色为例)

Design a website interface using a monochromatic color scheme based on blue. The primary blue is #0d6efd. Use its tints (e.g., #e6f0ff for background, #b3d1ff for lighter elements) and shades (e.g., #0059b3 for hover states, #004080 for text) to create depth and hierarchy. Ensure high contrast between text and background for readability. Use a clean sans-serif font like 'Roboto'. The layout should be minimalist and professional, with clear visual separation achieved through variations in the blue hue. Cards can be white (#ffffff) with subtle blue-tinted shadows.

（中文解释：使用基于蓝色的单色配色方案设计一个网站界面。主蓝色为 #0d6efd。使用其色调（例如，背景使用 #e6f0ff，较浅元素使用 #b3d1ff）和色度（例如，悬停状态使用 #0059b3，文本使用 #004080）来创建深度和层次感。确保文本和背景之间的高对比度以保证可读性。使用像 'Roboto' 这样的简洁无衬线字体。布局应简约专业，通过蓝色调的变化实现清晰的视觉分离。卡片可以是白色（#ffffff），带有微妙的蓝色阴影。）

主题 CSS 代码片段

以下是将此单色系风格（以蓝色为例）应用为全局主题的核心 CSS 代码 (body.theme-monochromatic)。它定义了基础蓝色的不同变体，并应用于各个元素：


/* ==========================================================================
   16. Monochromatic Theme (Example: Blue)
   ========================================================================== */

body.theme-monochromatic {
    /* Define variations of the base blue color */
    --mono-base: #0d6efd;       /* Base Blue */
    --mono-lightest: #e6f0ff;   /* Very light blue (tint) */
    --mono-lighter: #b3d1ff;    /* Lighter blue (tint) */
    --mono-light: #66a3ff;      /* Light blue (tint) */
    --mono-dark: #0059b3;       /* Darker blue (shade) */
    --mono-darker: #004080;      /* Even darker blue (shade) */
    --mono-darkest: #00264d;     /* Deepest blue (shade) */
    
    /* Text colors for contrast on light/dark mono backgrounds */
    --mono-text-light: #ffffff; /* For text on dark mono backgrounds */
    --mono-text-dark: var(--mono-darkest); /* For text on light mono backgrounds */

    /* Apply monochromatic variables to theme properties */
    --page-bg: var(--mono-lightest);
    --page-bg-gradient: none;
    --text-color: var(--mono-darker);
    --heading-color: var(--mono-darkest);
    --link-color: var(--mono-base);
    --link-hover-color: var(--mono-dark);
    --border-color: var(--mono-lighter);
    
    --card-bg: #ffffff; /* Cards are typically white or a very light tint in this scheme */
    --card-shadow: 0 2px 4px rgba(0, 64, 128, 0.1); /* Subtle shadow using a darker blue tone */
    --card-hover-shadow: 0 4px 8px rgba(0, 64, 128, 0.15);
    
    --header-bg: var(--mono-base);
    --header-text-color: var(--mono-text-light);
    --header-shadow: none;
    
    --footer-text-color: var(--mono-dark);
    --footer-bg: var(--mono-lightest); /* Footer matches page background */
    
    --button-bg: var(--mono-base);
    --button-text-color: var(--mono-text-light);
    --button-hover-bg: var(--mono-dark);
    --button-border: none;
    
    --button-secondary-bg: var(--mono-light);
    --button-secondary-text-color: var(--mono-text-dark);
    --button-secondary-hover-bg: var(--mono-lighter);
    --button-secondary-border: none;
    
    --prompt-bg: var(--mono-lighter); /* Prompt area uses a lighter blue */
    --prompt-text-color: var(--mono-darker);
    
    --base-font: var(--font-roboto); /* Example font */
    --heading-font: var(--font-roboto);
    
    --card-border-radius: 5px;
    --button-border-radius: 5px;
}

/* Specific adjustments for the theme */
body.theme-monochromatic .card {
    border: 1px solid var(--border-color); /* Ensure cards have the border */
}

/* Ensure buttons inherit theme colors */
body.theme-monochromatic .btn {
    background-color: var(--button-bg);
    color: var(--button-text-color) !important;
    border-radius: var(--button-border-radius);
}
body.theme-monochromatic .btn:hover {
    background-color: var(--button-hover-bg);
}
body.theme-monochromatic .btn-secondary {
    background-color: var(--button-secondary-bg);
    color: var(--button-secondary-text-color) !important;
}
body.theme-monochromatic .btn-secondary:hover {
    background-color: var(--button-secondary-hover-bg);
}

注意：单色系设计的美感在于其简洁和色彩的微妙变化。确保在不同色调之间有足够的对比度，以保证可访问性和视觉层次。
