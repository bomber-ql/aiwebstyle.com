Style Comparisons

Two styles, one identical page, and the decision that separates them.

The question is never which style is better

It is which style is better for this page, with this content, for this reader. A comparison that ends in a ranking has not helped anyone choose — so each page below puts two styles on identical markup and names the specific dimension where they diverge.

The panels are live. Scroll one and the other follows, so the same headline, the same three services and the same footer move past each other at once. That is the only honest way to compare two design systems: hold the content still.

01

Liquid Glass vs Glassmorphism

Glassmorphism floats — a large soft outer shadow, a hover lift, and a light streak that fades at both ends. Liquid Glass sits — a hard uniform top highlight, a heavier border, and no shadow at all.

Liquid Glass · Glassmorphism → 02

Brutalism vs Neo-Brutalism

Brutalism is one accent on paper. Neo-brutalism is five candy fills on cream, with a deeper shadow stack — same skeleton, completely different temperature.

Brutalism · Neo-Brutalism → 03

Editorial vs Swiss Style

Editorial controls line length — a 17-character headline and a 46-character standfirst. Swiss controls column position — a headline across nine of twelve columns, with the standfirst starting at column seven, deliberately overlapping.

Editorial / Magazine · Swiss Style / International Typographic Style → 04

Bento Grid vs Editorial

Bento tiles the page into modules of unequal size separated by one constant gap. Editorial has no modules at all: every text block is capped by line length, and the layout is whatever that cap produces.

Bento Grid · Editorial / Magazine → 05

Bento Grid vs Neo-Swiss

Bento's grid holds filled tiles of different sizes. Neo-Swiss's grid holds unfilled text blocks placed asymmetrically — a headline across nine columns, a standfirst starting at seven, deliberately overlapping.

Bento Grid · Neo-Swiss → 06

Neomorphism vs Claymorphism

Neumorphism carves: the element is the same colour as the surface, and the shadow pair is what makes it appear raised or pressed. Claymorphism colours: each card has its own pastel fill, a 26px radius, and a shadow pair that sits entirely outside it.

Neomorphism · Claymorphism → 07

Aurora UI vs Liquid Glass

Aurora moves the background: soft colour fields drift behind static glass. Liquid Glass holds the background still and puts the work into the panel edge — a hard inset highlight and a heavier border, with no shadow at all.

Aurora UI · Liquid Glass → 08

Retro 90s vs Retro Y2K

The 90s page has no gradients at all — depth comes from four-colour bevels on square boxes, navy and yellow, and links that are underlined by default. Y2K has gradients everywhere, rounded corners, white borders and a chrome finish.

Retro - 90s Web · Retro - Y2K Aesthetic → 09

Monochromatic vs Dark Mode

Monochromatic uses a single hue and varies only its lightness — every grey on the page is the same blue. Dark mode uses neutral surfaces and varies value in tight steps, reserving colour for one accent.

Monochromatic Design · Dark Mode → 10

Acid Graphics vs Neo-Brutalism

Acid graphics runs on black, one lime accent and tightly packed negative tracking, with a fixed 5-degree skew. Neo-brutalism runs on cream, five pastel fills and 8px hard shadows, with everything upright.

Acid Graphics · Neo-Brutalism →

How these pages are built

Both previews on every comparison page are the same HTML file rendered twice with different stylesheets. Nothing is redrawn for the comparison, and no screenshot is involved — so what you see is what the style actually does to a real page, including the parts that only appear on a narrow screen.

The decision table is a judgement, and several rows are deliberately marked as ties. Where one side genuinely handles something better, a dot marks it; where the answer depends on your content, it does not.
