What the Sustainable / Green Design style is doing

This page is defined by what it removes: no shadows, no webfonts, no decorative graphics, and no card containers. Sections are separated by a 2px green rule on the left of each service, and the space between blocks does the work that borders normally do. It is also the fastest page in the gallery, because there is nothing to download beyond one CSS file.

  • Zero box-shadows on the entire page
  • A 2px green rule replaces the service cards
  • System fonts only — no webfont request
