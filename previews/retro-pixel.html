What the Retro - Pixel Art style is doing

Pixel type only survives at two conditions: a size that lands on the font's pixel grid, and line height near double. At 0.46rem with 2.4 line height the glyphs stay legible; drop the line height and the bitmap rows collide into noise. Borders and spacing are multiples of four so the whole page sits on the same grid as the typeface, which is what makes it read as a system rather than a font choice.

  • Line height is close to double — the only setting that keeps bitmap type readable
  • Every border and gap is a multiple of four pixels
  • One neon green on near-black, no gradients
