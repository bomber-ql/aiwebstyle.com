What the Aurora UI style is doing

The usual implementation animates filter: blur on three huge elements, which forces the browser to re-blur them every frame. This version skips the filter entirely: each field is a radial gradient that already fades to transparent by 70 percent of its radius, so it is soft before it moves. Animation is transform only, at different durations per field, so they never sync into a pulse.

  • No blur filter anywhere — the softness is baked into the gradient
  • Each field runs at a different duration so they drift apart
  • Text sits on a scrim, never directly on the colour
