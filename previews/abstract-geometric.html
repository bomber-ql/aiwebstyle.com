What the Abstract / Geometric Shapes style is doing

The composition is the layout: a large circle and a square establish the page's weight before any text is read, and the type is positioned against them rather than centred in the viewport. Fills are pastel at low opacity so overlaps create a third colour without a third value being declared. One heavy grotesque anchors the whole thing, because geometric shapes plus a light typeface reads as an empty template.

  • Shapes set the composition before the type does
  • Overlapping translucent fills create new colours by blending
  • One heavy grotesque against large soft shapes
