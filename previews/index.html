Every preview below uses the same markup — the same headline, the same three services, the same footer. Only the stylesheet changes. That is the point: a style is a set of decisions about type, spacing, colour and depth, not a different website.

Open two in separate tabs and compare the same sentence. The content never moves; the voice changes completely.
