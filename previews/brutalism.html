What the Brutalism style is doing

Brutalism here is a set of refusals: no border radius, no gradient, no soft shadow, one typeface. Depth comes from a solid offset shadow with zero blur, which reads as a printed block rather than a floating card. Hovering a button translates it into the shadow instead of changing colour, so the feedback is spatial rather than chromatic. The accent is a single flat acid yellow used on exactly one panel.

  • The shadow has no blur at all — it is a solid offset block
  • Buttons move on press instead of changing colour
  • Arial is left unsmoothed on purpose, so edges look slightly rough
