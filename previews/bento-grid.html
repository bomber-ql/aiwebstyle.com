What the Bento Grid style is doing

A bento layout is a grid with two tile sizes and one rule: the gap never changes. Here the hero tile spans two columns and two rows, secondary tiles span two columns, and everything else is a single cell. Because the gap is constant at 16px, the tiles read as one object rather than a set of cards, which is the difference between a bento and a masonry gallery.

  • One gap value, 16px, everywhere
  • The hero tile is exactly 2x2, not 2.3 by 1.7
  • All tiles share one radius and one border colour
