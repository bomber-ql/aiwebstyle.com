Why prompts, not snippets

A copied CSS snippet solves today's problem and nothing else — it does not survive a redesign, a different framework, or a model that decides to rewrite your markup. A prompt that states the mechanism, the constraints and the failure mode transfers. That is why every entry here leads with the prompt and treats the code as evidence that it works.

The four things every prompt on this page specifies, and which most prompts leave out:

  • The trigger — load, scroll position, pointer position, or a state change. Ambiguity here is why an AI gives you a hover effect when you wanted a scroll one.
  • The property budget — transform and opacity only. The moment a model animates top or height, the effect drops off the compositor and stutters.
  • The fallback — what happens in a browser or a preference setting that cannot run it.
  • The ceiling — a number. Strength, duration, displacement. Without one, models overshoot, because "noticeable" is not a measurement.
